# Open UI Kit - Overview

<p class="description">Open UI Kit is a React component library and theme system for building consistent product interfaces on top of Material UI.</p>

## Introduction

Open UI Kit packages product-ready React components, shared theme tokens, and documentation in one place.
It uses Material UI as the foundation, then adds the Open UI Kit palette, typography, component defaults, and application patterns.

Use it when you want the flexibility of MUI with a stronger baseline for internal tools, dashboards, and workflow-heavy applications.

:::info
The goal is simple: keep the MUI developer experience, but make the default interface feel like Open UI Kit from the first render.
:::

## What you get

- **Product-ready defaults:** Components ship with consistent spacing, states, and density choices.
- **Shared themes:** Light and dark themes use the same token vocabulary across the package.
- **MUI compatibility:** You can still use Material UI APIs, `sx`, slots, and theme overrides where needed.
- **Documentation-first workflow:** Installation, usage, support, and version notes live beside the component docs.

## Start now

1. Install the package and peer dependencies.
2. Wrap your app with `ThemeProvider`.
3. Import components from `@open-ui-kit/core`.
4. Use the component docs to tune props, patterns, and behavior.
