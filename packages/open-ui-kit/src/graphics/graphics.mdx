## Sizes

Graphics accept `fontSize="base" | "small" | "medium" | "large" | "xlarge"`.
These category names belong to the graphics API and intentionally resolve to
different pixel values than identically named icon categories.

| Category | Graphic size |
| --- | --- |
| `base` | 20 × 20 px |
| `small` | 24 × 24 px |
| `medium` | 32 × 32 px (default) |
| `large` | 48 × 48 px |
| `xlarge` | 64 × 64 px |

```tsx
import { Graphics } from "@open-ui-kit/core";

<Graphics.ApiSecurityGraphicActive fontSize="large" />;
```
