## Sizes

Icons use the `fontSize` prop for the Open UI Kit size scale:

- `base`: 16px
- `small`: 20px
- `medium`: 24px (default; use for more complex icons)
- `large`: 32px
- `inherit`: the surrounding font size

```tsx
<Icons.Check fontSize="base" />
<Icons.Close fontSize="small" />
<Icons.Settings />
<Icons.Settings fontSize="large" />
```
